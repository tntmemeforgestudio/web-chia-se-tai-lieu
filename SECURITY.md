# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** open a public issue. Instead, send a private report to **TNT MemeForge Studio**.

All security vulnerabilities will be promptly addressed and patched.
